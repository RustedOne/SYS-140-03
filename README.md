# SYS-140-03

Operating System Fundamentals class notes. The notes are published to the [wiki](https://github.com/RustedOne/SYS-140-03/wiki).

## How the wiki is published

- Pages and images live in the `wiki/` folder of this repo (images go in `wiki/images/week-N/`).
- On every push to `main` that changes `wiki/`, the **Publish wiki** action copies that folder into the wiki.
- Pages created in the wiki's web editor are left alone. To delete a wiki page, add its file name to `wiki/.remove`.
- Page file names become wiki titles: `Week-2-‐-Processes.md` shows as "Week 2 ‐ Processes".
